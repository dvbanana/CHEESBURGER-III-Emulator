it's just currently very much unfinished if you'd like to contribute Help would very much be appreciated Beware you have to use [this](https://godotengine.org/download/archive/4.2.2-stable/) very specific version of Godot it also has to be the .net version or it probably won't work, After godot's installed Simply just open Godot and then Click Import And then select wherever git put all the files. 

There is a spreadsheet With all of the instructions that are currently implemented In the assembler folder. 
beware merging spreadsheets does not work very well with git so if you are contributing leave the spreadsheet be And just wait for me to update it.


Instructions:
Drag a .as file onto the program to load it.
Make sure that python is installed and that the python command in the command line works correctly.
Press control+s or f5 to save the assembly code and assemble and load the bytecode,
Assembled bytecode is stored in the same directory as the .as file but with a .mc extension.
